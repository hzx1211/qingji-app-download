# 轻记 Android 体验版

轻记是一款使用 Flutter 开发的本地优先个人减脂与血压记录应用。

- 当前版本：2.2.0+11
- 主要功能：体重、腰围、血压与心率记录，饮食计划，趋势回顾，系统提醒和数据导入导出。
- 可选 AI 功能：菜单建议和食物识别；需要用户自行配置服务密钥。
- 数据默认保存在设备本地；使用 AI 功能时，会向用户配置的服务发送该功能需要的数据。
